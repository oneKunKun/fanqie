# 《雾城拾荒者》小说大纲

一、基本信息

小说名称：《雾城拾荒者》
小说类型：末日科幻、悬疑、冒险
频道：男频
主角姓名：陆沉
一句话描述：在一座每天都会遗忘部分历史的末日城市里，底层拾荒者陆沉发现，自己竟是唯一能保留全部记忆的人。
预计字数：120万字
目标读者：喜欢末日生存、升级冒险、悬疑解谜和群像故事的读者

二、故事背景

二百年前，人类启动“天穹计划”，试图利用人工智能控制全球气候。实验失败后，一种被称为“灰雾”的物质覆盖大地。灰雾会腐蚀机械、改变生物，并周期性抹除人类的部分记忆。

幸存者居住在由高墙保护的第七城。城市按照高度分为上城、中城与下城：上城掌握能源与知识，中城负责生产，下城居民则依靠回收废墟中的旧时代物资生存。

每隔三十天，城市都会经历一次“遗忘日”。居民必须依靠官方保存的身份档案重新认识亲人、工作和过去。然而，官方档案并不完全真实。

三、世界核心规则

1. 灰雾会侵蚀生命和机械。
2. 长期接触灰雾的人可能觉醒特殊能力，也可能变成怪物。
3. 所有人的记忆都会在遗忘日受到影响。
4. 文字记录也会发生变化，只有特殊的“黑匣纸”能够保存真实信息。
5. 陆沉拥有完整记忆，但每次抵抗遗忘都会付出身体代价。

### 能力与侵蚀双轴体系

实力不采用单一战斗等级，而由“能力阶段”和“灰雾侵蚀等级”共同决定。能力越强不代表战斗必胜，训练、装备、环境和情报仍能改变结果。

**能力阶段**

1. 触雾：出现异常感知，能力尚不稳定。
2. 觉醒：形成一种固定能力，可以主动使用。
3. 锚定：建立稳定的自我锚点，能够控制代价并开发能力。
4. 共鸣：能力可影响多人、区域或天穹系统。
5. 失控：失败状态而非更高阶段；人格或身体被灰雾吞噬。

**灰雾侵蚀等级**

0级·稳定：无明显污染症状。
1级·轻蚀：头痛、流血或短暂幻觉。
2级·混忆：外来记忆侵入，自我身份开始动摇。
3级·失我：无法稳定区分自身与他人记忆。
4级·异变：身体发生不可逆变化，成为失控体或雾兽类存在。

陆遥与零号属于系统级存在，不纳入普通觉醒者等级。该体系从第十章起通过白塔病历、研究记录和角色判断逐步展示，不集中说明。

### 能力体系硬规则

1. **核心能力唯一**：每名觉醒者只能形成一种核心能力。能力由其最深刻的记忆与灰雾共同塑造，后续只能开发同源用法，不能获得无关的第二能力。
2. **发动条件固定**：每种能力必须依赖明确媒介、距离或对象。能力不能突破自身信息边界；陆沉的记忆回响必须触碰物品，只能读取物品残留的过去，不能读取未来或凭空生成信息。
3. **记忆锚点有损耗**：进入锚定阶段前，觉醒者必须选择一段核心记忆或一件“锚物”固定自我。过度使用能力会磨损锚点；锚点被摧毁时，侵蚀可能直接进入2级·混忆或3级·失我。黑匣纸可以承载锚点，但不会自动替使用者消除代价。
4. **侵蚀不可逆退**：已形成的灰雾侵蚀不能通过休息、药物或过滤器真正降低。常规手段只能压制症状、延缓升级。白塔所谓的“侵蚀回退治疗”本质是删除相关记忆结构，会同时造成永久性人格缺损。

### 陆沉的成长与战斗路线

1. **基础战斗力**：陆沉具备拾荒者长期积累的短刀近战、废墟攀爬、潜行追踪、基础枪械和机械判断能力。身体不会因能力升级而获得超强力量或速度，正面对抗城防精锐仍需要队友、装备和环境。
2. **觉醒熟练期**：陆沉逐步学会主动开始和中断记忆回响，并从物品多层残留中筛选近期最强片段。战斗中可以通过接触武器、护甲、门锁和地形，判断刚发生的动作、维修弱点或逃跑方向，但不能预知下一招。
3. **一瞬回响**：觉醒阶段的战斗用法。短暂接触物品，只读取最近、最强烈的一个动作残留，用于判断敌人的收刀习惯、枪械故障或装备旧伤。连续使用会造成头痛、鼻血和动作记忆混杂；身体反应跟不上时，看懂也无法躲避。
4. **混忆代价**：第二卷中陆沉正式进入2级·混忆。该等级不可逆退，表现为混淆复制体经历、叫错名字、误认时间与继承物品原使用者的动作习惯。锚定只能维持自我，不能让侵蚀降级。
5. **短刀锚物**：陆沉进入锚定阶段时选择随身拼装短刀作为锚物。短刀仍是普通装备，不产生超自然能力；它的重要性来自陆沉亲历的磨损、修复和选择。锚物被毁会使陆沉迅速逼近3级·失我。
6. **锚定用法**：锚定后可使用残响分层、定点回溯和自我校验；还可在身体能力允许时复现物品残留中的单个动作，但不能继承整套技能，同一场战斗只能有限使用。
7. **环境猎杀**：陆沉的核心战斗风格是“接触—判损—借势—近战”。他通过读取承重结构、旧机械、护甲维修和雾兽撞击残留寻找弱点，再用短刀、枪械或环境完成攻击，而非依靠能力直接造成伤害。
8. **共鸣阶段**：后期陆沉只能通过实际连接的设备或天穹网络，把自己读取到的既有残留共享给队友或全城。共鸣不是预知、读心、精神控制或凭空制造记忆；终局公开全城真相属于该能力的最高应用。
9. **装备成长**：短刀可以更换耐腐蚀刃、护手、破甲尖端和可开合绝缘握持结构；唐梨负责工具、过滤器、绳索和侦察设备的升级。所有改造均为工程装备，不附带灰雾能力。

### 多个零七载体的处理原则

1. 最初的陆沉已经无法凭官方档案或记忆链找回；历代载体继承相同过去，但从醒来后便因不同经历成为独立的人。
2. 当前陆沉始终是叙事主角，却不会被宣布为唯一真品；八十四号会逐渐放弃编号并选择自己的名字和人生。
3. 05:17腕带男性定位为本次替换流程中的备用载体，黑箱返空者定位为保存六号线早期残缺记忆的历史载体；两人的具体身份须通过后续证据逐步确认。
4. 地下历代载体多数处于死亡、空白或无法独立行动状态。真正苏醒并进入主要剧情的复制体总数控制在三至四人，不发展“陆沉军团”。
5. 不使用所有复制体合并、被主角吸收或为清理角色连续牺牲的处理。复制体共享记忆来源，但不会共享人格、能力和生命。

四、主要势力

天穹议会：第七城的最高统治机构。
城防局：负责抵御雾兽、镇压下城骚乱。
拾荒者公会：控制废墟探索和旧时代物资交易。
白塔研究院：研究灰雾、记忆与觉醒者。
无名者：一群拒绝接受官方身份的人。
雾中教团：相信遗忘是人类进化的必要过程。

五、核心冲突

陆沉想查明妹妹失踪的真相，却逐渐发现妹妹并非普通失踪者，而是维持整座第七城运转的“记忆核心”。如果救出妹妹，城市可能毁灭；如果放弃她，所有居民将永远活在被编造的历史中。

六、主要角色

陆沉：22岁，下城拾荒者。冷静、警惕、嘴硬心软。能力为“记忆回响”，可以读取物品残留的记忆片段。使用能力会加速灰雾侵蚀，并逐渐混淆自己与他人的记忆。他的目标是找到失踪的妹妹陆遥。随身短刀属于拼装装备，是结构简单、耐腐蚀且便于打磨维修的多用途工具兼近身武器；它没有灰雾能力，也不是旧世遗物，具体来源尚未揭示。

陆遥：陆沉的妹妹，白塔实验体。温柔而坚定，真实身份是第七城的记忆核心。

苏烬：城防局队长，果断克制，是陆沉的对手兼盟友。他暗中调查父亲死亡的真相，最终背叛城防局。

唐梨：下城机械师，活泼、贪财，是陆沉的搭档。最初梦想进入上城，后来选择留在下城帮助居民。

陈默：无名者首领，陆沉的导师。理性而偏执，计划摧毁全部记忆核心。

顾长夜：白塔院长，儒雅冷酷。试图通过控制记忆维持城市秩序，最终与旧天穹系统融合。

零号：旧时代人工智能。它将观察并判断人类是否值得延续，最终把选择权交给陆沉。

七、故事主线

遗忘日前夕，陆沉在禁区废墟中找到一张保存着妹妹笔迹的黑匣纸，上面写着：“哥哥，不要相信遗忘之后的我。”第二天，所有人都忘记了陆遥，城市档案中也没有她存在过的痕迹。

陆沉为寻找妹妹闯入封锁区，意外觉醒“记忆回响”。随后城防局将他列为记忆污染者，他必须一边逃亡，一边寻找能够证明陆遥存在的三个记忆坐标。

陆沉进入白塔后发现，陆遥已经成为第七城的记忆核心。每次遗忘日，城市都会抽取她的记忆，用来覆盖居民发现过的真相。

顾长夜最终启动永久遗忘计划，试图删除所有居民的个人记忆。无名者则准备炸毁白塔，但此举也会杀死陆遥并摧毁城市防护系统。

最终，陆沉进入天穹主机，选择开放全部记忆，让全城居民共同承担真相。他以自身作为记忆中继器，终止了遗忘循环。陆遥获救，却失去了与哥哥有关的大部分记忆。兄妹二人离开第七城，前往灰雾深处寻找其他城市。

九、分卷规划

第一卷《遗忘之日》：陆沉发现妹妹被全城遗忘，觉醒记忆回响。
第二卷《城外之雾》：小队探索废墟，寻找三个记忆坐标。
第三卷《白塔之下》：潜入研究院，发现陆遥是记忆核心。
第四卷《无名之城》：各方势力争夺天穹系统，下城全面起义。
第五卷《最后的记忆》：永久遗忘计划启动，陆沉开放全城记忆。
第六卷《灰海之外》：众人重建秩序并探索城外，发现其他城市的信号。

十、主题

记忆会骗人，历史会被改写，但人仍然可以选择自己要成为什么样的人。
